مرجع CSS الكامل

لغة تنسيق صفحات الويب

تعلّم كيف تُحوّل هيكل HTML إلى واجهة جميلة ومتجاوبة: المحددات، الألوان، الصندوق، التخطيط، Flexbox، Grid، الحركات، والتصميم المتجاوب.

مقدمة إلى CSS

ما هي CSS؟

CSS اختصار لـ Cascading Style Sheets أي «أوراق الأنماط المتتالية». هي اللغة المسؤولة عن شكل الصفحة: الألوان، الخطوط، المسافات، الأبعاد، والتخطيط. إذا كانت HTML هي الهيكل العظمي، فإن CSS هي الملابس والشكل النهائي.

h1 {
  color: #1e90ff;
  font-size: 32px;
  text-align: center;
}

هذا المثال يختار كل عناصر <h1> ويجعل لونها أزرق وحجمها 32 بكسل ومحاذاتها في المنتصف.

لماذا نستخدم CSS؟

  • الفصل بين المحتوى والشكل: يبقى HTML للهيكل فقط، مما يجعل الكود أنظف وأسهل في الصيانة.
  • إعادة الاستخدام: قاعدة واحدة يمكن أن تنسّق مئات العناصر في كل الصفحات.
  • التصميم المتجاوب: تغيير الشكل حسب حجم الشاشة عبر Media Queries.
  • الحركة والتفاعل: الانتقالات والتحويلات والحركات بدون كتابة JavaScript.

الوراثة والمبدأ الأساسي

فكرة CSS بسيطة: تخبر المتصفح «عندما تجد عنصراً كهذا، اعرضه بهذه الطريقة». المتصفح يطبّق القواعد ثم يحسم أيها يفوز عند التعارض حسب التتالي (Cascade) والخصوصية (Specificity).

الصياغة (Syntax)

تشريح القاعدة

تتكوّن كل قاعدة CSS من جزأين: المحدد (Selector) الذي يحدد العناصر، وكتلة التصريحات بين قوسين تحتوي على خاصية وقيمة.

p {
  color: blue;
  font-size: 16px;
}
الجزءالمعنىمثال
Selectorيختار العناصر المستهدفةp أو .card
Propertyاسم الخاصية التي نريد تغييرهاcolor
Valueالقيمة المطبقة على الخاصيةblue
Declarationزوج خاصية وقيمة ينتهي بفاصلة منقوطةcolor: blue;

قواعد يجب تذكّرها

  • كل تصريح ينتهي بفاصلة منقوطة ; وكل كتلة تفتح بـ { وتغلق بـ }.
  • أسماء الخصائص والقيم غير حسّاسة لحالة الأحرف، لكن الأفضل الكتابة بحروف صغيرة.
  • يمكن كتابة أكثر من محدد يفصل بينهم فاصلة لتطبيق نفس القاعدة محمدهم جميعاً.
  • المسافات الزائدة لا تؤثر على النتيجة، لكن التنسيق الجيد يسهّل القراءة.
h1, h2, h3 {
  font-family: Tahoma, Arial, sans-serif;
  color: #2f3542;
}

طرق إضافة CSS: Inline و Internal و External

CSS مضمّن (Inline)

يُكتب داخل خاصية style على العنصر نفسه. أعلى أولوية، لكنه يصعّب الصيانة ويكرر الكود، لذا يُستخدم بحالات نادرة.

<p style="color: red; font-size: 18px;">نص أحمر بحجم أكبر</p>

CSS داخلي (Internal)

يُكتب داخل عنصر <style> في رأس الصفحة، وينطبق على الصفحة بأكملها. مناسب للصفحات الصغيرة وللتعلم.

<head>
  <style>
    body {
      background: #f1f2f6;
    }
  </style>
</head>

CSS خارجي (External)

يُكتب في ملف مستقل بامتداد .css ويُربط بالصفحة عبر <link>. الأسلوب المفضّل للمشاريع الكبيرة لأنه يُخزّن مؤقتاً في المتصفح ويُعاد استخدامه بين كل الصفحات.

<link rel="stylesheet" href="style.css">
ترتيب الأولوية: عند التعارض يفوز الـ Inline، ثم الـ Internal/External حسب ترتيب ورودها، وتُحسم البقية بالخصوصية ثم التتالي.

محددات متقدمة

تتيح لك اختيار عناصر بذكاء أكبر اعتماداً على خصائصها أو موضعها.

a[href^="https"] { color: green; }
a[href$=".pdf"] { font-weight: bold; }
img[alt*="شعار"] { opacity: 0.9; }

^= يعني «يبدأ بـ»، $= يعني «ينتهي بـ»، و*= يعني «يحتوي على».

ملاحظة: الـ ID يجب أن يكون فريداً في الصفحة، بينما الـ class قابل للتكرار على عناصر كثيرة. الأفضل الاعتماد على الـ class أكثر من الـ ID في التنسيق.

عوامل الدمج (Combinators)

أنواع الدمج

العاملالمثالالمعنى

متى تستخدم أيّها؟

استخدم الابن المباشر > عندما تريد تقييد التنسيق بطبقة واحدة دون التأثير على العناصر المتداخلة بعمق، واستخدم + لتنسيق عنصر يعقب آخر مباشرة مثل تنسيق أول فقرة بعد عنوان.

الخصوصية (Specificity)

كيف يحسم المتصفح التعارض؟

عندما تنطبق قاعدتان على نفس العنصر، يفوز الأكثر خصوصية. تُحسب الخصوصية كسلسلة من الأوزان: الأنماط المضمّنة (Inline)، ثم الـ ID، ثم الـ class والـ attribute والـ pseudo-class، ثم أسماء العناصر.

المحددالوزن التقريبي
Element (p)1
Class / Attribute / Pseudo-class (.card, [type], :hover)10
ID (#header)100
Inline style1000
!importantيتجاوز كل ما سبق
 
p { color: black; }
.text { color: blue; }
#main { color: red; }

العنصر <p id="main" class="text"> سيظهر بلون أحمر لأن الـ ID أقوى من الكلاس والعنصر.

نصيحة: تجنّب !important إلا في حالات الضرورة القصوى، لأنه يكسر سلسلة التتالي ويجعل الصيانة صعبة. حسّن ترتيب محدداتك بدلاً منه.

التتالي والوراثة (Cascade & Inheritance)

ترتيب التتالي

يحسم المتصفح النتيجة النهائية بترتيب ثابت: أولاً مصدر النمط وأهميته، ثم الخصوصية، ثم ترتيب الظهور. القاعدة الأحدث في نفس المستوى تفوز على الأقدم.

الوراثة

بعض الخصائص مثل color وfont-family تُورَّث من العنصر الأب إلى الأبناء تلقائياً، بينما خصائص مثل margin وborder لا تُورَّث.

body { font-family: Tahoma; color: #333; }
.inherit { color: inherit; }
.reset { color: initial; }
.fixed { color: unset; }
القيمةالمعنى
inheritخذ القيمة من العنصر الأب
initialأعد القيمة الافتراضية للخاصية
unsetوراثة إن كانت موروثة، وإلا القيمة الافتراضية

التدرجات (Gradients)

التدرّج الخطي Linear

ينتقل اللون على خط مستقيم بزاوية أو اتجاه محدد. يمكن إضافة عدة محطات ألوان.

.linear {
  background: linear-gradient(45deg, #1e90ff, #6c5ce7);
}
.stripes {
  background: linear-gradient(to right, red 0 20px, white 20px 40px);
}

التدرّج الدائري Conic و Radial

.radial {
  background: radial-gradient(circle, #fff, #1e90ff);
}
.conic {
  background: conic-gradient(#1e90ff, #6c5ce7, #1e90ff);
}

التدرّج الدائري يبدأ من نقطة وينتشر للخارج، والتدرّج المخروطي يدور حول نقطة كعقارب الساعة.

أفضل الممارسات والصيانة والأداء

تنظيم الكود

  • حرّك خصائص transform وopacity فهي أرخص على المتصفح من width وtop.

  • قلّل الـ box-shadow والتمويه الثقيل داخل العناصر المتحركة.

مرجع JavaScript الكامل

لغة برمجة الويب التفامحمدة

من المتغيرات والدوال إلى الـ DOM والأحداث والوعود fetch: مرجع عملي مبني على أمثلة حقيقية لبناء صفحات تفامحمدة.

مقدمة إلى JavaScript

ما هي JavaScript؟

JavaScript لغة برمجة تُنفَّذ مباشرة داخل المتصفح بلا حاجة إلى ترجمة مسبقة. تتحكم في سلوك الصفحة: تستجيب للنقر والكتابة، تُعدّل HTML و CSS في الوقت الحقيقي، تتحقق من النماذج، وتجلب البيانات من الشبكة.

document.querySelector("h1").addEventListener("click", function () {
  alert("ضغطت على العنوان!");
});

كيف تعمل داخل المتصفح؟

يمتلك المتصفح محرّك JavaScript ينفّذ الكود سطراً بسطر. يوفّر لك الأخير واجهات جاهزة أهمها الـ DOM للتلاعب بالصفحة، وfetch للشبكة، وlocalStorage للتخزين.

<script src="app.js" defer></script>
لماذا defer؟ يجعل المتصفح ينفّذ السكربت بعد بناء الصفحة، فتجد كل عناصر DOM جاهزة دون إبطاء العرض.

أول برنامج
